# Task: Complete and verify one integer GSN/GSU neuron cell

- Owner: Codex
- Status: completed
- Branch: `codex/gsn-cell`
- Interpretation: the project configuration calls the sequence model `GSN`,
  while the integer neuron implementation is `IntegerGSUCellReference`. This
  task implements one neuron-state cell below the matrix-accumulator boundary.
- Scope:
  - Accept one neuron's INT32 input and recurrent accumulators plus previous
    INT8 state and exported per-neuron parameters.
  - Execute forget/cell gate requantization, bias and guard shift, 255-entry
    sigmoid, membrane update, folded-BN requantization, state saturation, spike
    decision and tagged result handoff.
  - Reuse one `pe_requant_lane`, one `pe_hybrid_mac`, and
    `pe_sigmoid_lut_255`; keep exactly one transaction in flight.
  - Generate independent vectors from both real fullband GSN cells in
    `upstream/parameters/parameters.bin`, including all 320 neuron parameter
    channels per layer and explicit boundary cases.
  - Run self-checking Windows Vivado 2018.3 XSim and XC7Z020 OOC synthesis.
- Out of scope:
  - Weight matrix traversal and accumulation across a complete input vector;
    those remain the 16-PE Array responsibility.
  - Replicating this standalone cell 320 times, production AXI/memory wiring,
    full implementation, bitstream, RTF or board measurement.

## PYNQ-Z1 feasibility

- Placement: PL RTL, standalone neuron-state core after PE matrix accumulation.
- Target part / clock: `xc7z020clg400-1`, 200 MHz OOC; production AXI remains
  100 MHz and needs CDC outside this cell.
- Numeric formats and shapes: one neuron transaction; INT32 input/recurrent
  accumulators and bias, signed 32-bit requant multipliers, 6-bit shifts, INT8
  previous/gate/state, unsigned 8-bit sigmoid lambda, guard shift fixed at 8.
- Parallel instances / lanes: one validation instance containing one Hybrid MAC,
  one shared requant lane and one 255-byte sigmoid LUT. It is not a 320-cell
  replicated architecture.
- Pre-implementation estimate: below 1,500 LUT, 1,000 FF, 5 DSP and at most one
  BRAM18. Measured post-synthesis OOC: 1,172 LUT, 1,484 FF, 5 DSP and one
  BRAM18. The FF estimate was low; measured utilization remains acceptable for
  one validation instance.
- Scaled total: same as one instance. Replicating 16 copies would consume about
  80 DSP before other PE resources and is therefore not the selected system
  architecture.
- Local state/ports: parameter registers, seven intermediate INT64 requant
  values, one INT8 previous/new state and a 255-byte configurable LUT. No weight
  cache or frame buffer.
- DDR/AXI: none locally. Accumulators/parameters arrive from later PE/memory
  integration; per-neuron parameter bandwidth remains a system concern.
- Measured cycles/II: fixed 100-cycle latency per neuron at 200 MHz; only one
  transaction in flight. The additional pipeline stages close 5 ns timing.
- Clock domains/CDC: one 200 MHz synchronous active-low-reset domain; no CDC.
- Hot spot: one standalone cell duplicates a four-DSP 32x32 requant lane. The
  production 16-neuron schedule should continue sharing the four-lane Local RQ
  bank rather than instantiating sixteen cells literally.
- Fallback: keep this module as the bit-exact neuron reference wrapper and map
  its schedule onto the existing 16 Hybrid PEs plus four-lane Local RQ bank.
- Evidence level: Python bit-exact reference, Windows Vivado 2018.3 XSim, and
  XC7Z020 post-synthesis OOC. No implementation or board evidence.
- Feasibility: `PASS WITH ARCHITECTURAL RISK` for one instance; replicated
  per-neuron deployment is not approved.

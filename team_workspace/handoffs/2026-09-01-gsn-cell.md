# Handoff: bit-exact single GSN/GSU neuron cell

- Branch: `codex/gsn-cell`
- Scope completed: one neuron below the matrix-accumulator boundary, deterministic
  real-parameter vector export, self-checking XSim, and XC7Z020 5 ns OOC synthesis.
- RTL: `rtl/pe_array/rtl/gsn/pe_gsn_cell.sv`.
- Chinese result report: `rtl/pe_array/reports/pe_gsn_cell/summary.md`.
- Reproduction:
  1. `python3 rtl/pe_array/reference/pe_gsn_cell_reference.py`
  2. Run `rtl/pe_array/scripts/sim/run_pe_gsn_cell_xsim.tcl` with Windows Vivado
     2018.3 and `rtl/pe_array` as the first Tcl argument.
  3. Run `rtl/pe_array/scripts/synth/synth_pe_gsn_cell_ooc.tcl` the same way.
- Results: 672/672 vectors PASS, fixed latency 100 cycles, 96 result stalls,
  63 unique clipped vectors. OOC uses 1,172 LUT, 1,484 FF, 5 DSP and 1 BRAM18;
  WNS is +0.263 ns at 5 ns.
- Important boundary: input/recurrent weight MACs are external INT32 accumulators.
  This standalone one-cell wrapper is verification hardware, not a proposal to
  replicate 320 copies.
- Next step: schedule the equation across the existing 16 Hybrid PEs and 4-lane
  Local RQ bank, then add production parameter/memory streams and a multi-frame
  recurrent integration test.
